API Endpoints

GET /api/download?url={VIDEO_URL}

Extracts video metadata and all available direct streaming links.

GET /api/info?url={VIDEO_URL}

Alias for metadata and stream resolution query.

POST /api/convert

Accepts JSON {"url": "https://www.pornhub.com/view_video.php?viewkey=..."}.

GET /api/health

Check API server status and creator information.

# Python 3
import requests

url = "https://thenuxphdl.netlify.app/api/download"
params = {"url": "https://www.pornhub.com/view_video.php?viewkey=66db8ffed80aa"}
res = requests.get(url, params=params)
data = res.json()

print(f"Title: {data['data']['title']}")
print(f"Creator: {data['creator']}") # Thenux
for stream in data['data']['downloads']:
    print(f"[{stream['quality']}] -> {stream['url']}")

Deploy to GitHub & Netlify

Zero-Config Deployment

Push to GitHub

Push directly to the official GitHub repository:

git init

git commit -m "feat: PH Downloader API by Thenux"
git branch -M main

2

Connect with Netlify
